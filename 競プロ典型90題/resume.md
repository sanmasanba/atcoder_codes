# 競プロ典型90題 — 復習用要点

公式の[問題一覧](https://atcoder.jp/contests/typical90/tasks)に対応する、解法を思い出すための短いメモです。★の難問は「実装を再現するための核」を優先しているため、初見で解くときは先に自力で考え、詰まった後に公式解説を参照します。

## 001–010

- **001 Yokan Party** — 「最小のピース長を `x` 以上にできるか」は単調。左から貪欲に切って個数を数える判定を用意し、答えを二分探索する。
- **002 Encyclopedia of Parentheses** — 長さが小さいので `2^N` 個を全列挙。途中の開き括弧数が負にならず、最後に 0 なら正しい。
- **003 Longest Circular Road** — 木の直径。任意の頂点から最遠点 `s` を取り、`s` からの最遠距離 + 1 が答え。
- **004 Cross Sum** — 行和 `R[i]` と列和 `C[j]` を前計算し、各マスは `R[i]+C[j]-A[i][j]`。
- **005 Restricted Digits** — `dp[r]`: 桁列を `B` で割った余りが `r` の通り数。長さを 2 倍にする遷移を余りの畳み込みとして作り、二進累乗する。
- **006 Smallest Subsequence** — 各位置以降の各文字の次出現位置を前計算。残り文字数を確保できる範囲で最小の文字を貪欲に選ぶ。
- **007 CP Classes** — 配列をソートし、各質問値の lower_bound の前後だけ比較する。
- **008 AtCounter** — `dp[j]`: ここまでで目標文字列の先頭 `j` 文字を作る通り数。文字を使わない／一致すれば使う、の部分列 DP。
- **009 Three Point Angle** — 各頂点を中心に他点への偏角をソート。各角に対し `+180°` に最も近い角を二分探索する。
- **010 Score Sum Queries** — クラスごとに累積和を持ち、区間和を 2 本の累積和の差で求める。

## 011–020

- **011 Gravy Jobs** — 締切順にソートする 0/1 ナップサック。`dp[t]` を時刻 `t` までに得る最大報酬とし、締切以内に仕事を置く。
- **012 Red Painting** — 赤く塗ったマスだけを上下左右で Union-Find に併合。質問時は両端が赤、かつ同じ成分かを判定する。
- **013 Passing** — 頂点 1 と頂点 N を始点に Dijkstra を 2 回。頂点 `v` を通る最短距離は `d1[v]+dN[v]`。
- **014 We Used to Sing a Song Together** — 対応を自由に決められる絶対差和の最小化は、両配列をソートして同順位同士を組ませる。
- **015 Don't be too close** — 選んだ位置の差が `K` 以上になるよう、間隔 `K-1` 個を先に詰めて除く。選択数ごとに組合せで数える。
- **016 Minimum Coins** — 枚数上限が小さい 2 種の枚数を全探索し、残りが 3 種目で割り切れるか調べる。
- **017 Crossing Segments** — 左端順に走査し、右端を Fenwick Tree で管理。`l1<l2<r1<r2` となる組を累積して数える。
- **018 Statue of Chokudai** — 観覧車上の座標を三角関数で求める。水平距離と高さから `atan2(高さ, 水平距離)`。
- **019 Pick Two** — 区間 DP。両端を組ませるか、区間を偶数長の 2 区間に分けるかの最小値を取る。
- **020 Log Inequality** — 浮動小数点・対数を使わず、整数の累乗（オーバーフローに注意）で `a < c^b` を比較する。

## 021–030

- **021 Come Back in One Piece** — SCC に分解。各強連結成分の頂点数を `s` とすると、往復可能な順序対は `s(s-1)/2`。
- **022 Cubic Cake** — 最小単位の一辺は 3 辺の gcd。必要な切断回数は `A/g+B/g+C/g-3`。
- **023 Avoid War** — 行ごとの配置をビットで表す DP。壁を避けた合法マスクと、上下 2 行を含む攻撃が衝突しない互換性を列挙する。
- **024 Select +/- One** — 必要最小操作数は L1 距離 `Σ|Ai-Bi|`。余る操作数が偶数なら往復してちょうど K 回にできる。
- **025 Digit Product Equation** — 桁積に現れる素因数は 2,3,5,7 のみ。可能な桁積を指数全探索し、`x=b+product(x)` を候補として検証する。
- **026 Independent Set on a Tree** — 木を 2 部グラフに塗り分け、頂点数が十分な側から `N/2` 個取る。同じ側には辺がない。
- **027 Sign Up Requests** — 既出文字列を set に入れ、初登場時の番号だけ出力する。
- **028 Cluttered Paper** — 長方形の四隅に 2 次元いもすの差分を置き、横・縦の累積和後に被覆数を数える。
- **029 Long Bricks** — 区間の最大高さを取得し、その +1 で区間を一様に更新する。遅延セグメント木の range max / range chmax。
- **030 K Factors** — 各素数の倍数をふるい、各整数の異なる素因数数を加算。`K` 個以上の数を数える。

## 031–040

- **031 VS AtCoder** — 各山の状態の Grundy 数を mex で前計算し、全山の xor が 0 なら後手必勝。
- **032 AtCoder Ekiden** — `N≤10` 程度は走者順列を全探索。隣接禁止ペアを弾いて合計時間の最小を取る。
- **033 Not Too Bright** — 縦横とも 2 マス以上なら、互いに隣接しない行・列を選び `ceil(H/2)ceil(W/2)`。1 列・1 行は例外。
- **034 There are few types of elements** — 尺取り法で「種類数 ≤ K」を保つ最長区間を求める。頻度 0 の削除を忘れない。
- **035 Preserve Connectivity** — LCA と Euler Tour。指定頂点を Euler 順に並べ、隣接（最後→最初も含む）の距離和を 2 で割ると最小連結部分木の辺数。
- **036 Max Manhattan Distance** — `x+y, x-y` へ座標変換。各変換値の全体 min/max を持てば各点からの最大マンハッタン距離を O(1) で答えられる。
- **037 Don't Leave the Spice** — 重さ `j` の遷移元は連続区間 `[j-R,j-L]`。区間最大値をセグメント木（または deque）で取りナップサックを高速化する。
- **038 Large LCM** — `lcm(A,B)=A/gcd(A,B)*B`。先に割ってから上限超過を判定する。
- **039 Tree Distance** — 辺を切ったときの成分サイズを `s` とすると、その辺の寄与は `s(N-s)`。根付き木の部分木サイズで足す。
- **040 Get More Money** — 選ぶと利益、依存違反には大罰金を置く最大閉包問題。最大流・最小カットで「選ぶ集合」を求める。

## 041–050

- **041 Piles in AtCoder Farm** — 凸包を作り、Pick の定理 `格子点数=面積2/2+境界格子点数/2+1` を使う。境界格子点数は各辺の `gcd(|dx|,|dy|)`。
- **042 Multiple of 9** — 9 の倍数条件は桁和の 9 倍。`dp[s]=Σ dp[s-d] (d=1..9)` で、和 K の正整数列を数える。
- **043 Maze Challenge with Lack of Sleep** — 状態を `(マス, 向き)` にする。直進コスト 0、方向転換コスト 1 の 0-1 BFS。
- **044 Shift and Swapping** — 配列を実際に回さず、先頭オフセットだけ持つ。添字は `(i-offset) mod N` に変換する。
- **045 Simple Grouping** — 部分集合ごとの直径二乗を前計算。`dp[g][S]` を S を g グループに分けたときの最小最大値として部分集合 DP。
- **046 I Love 46** — 値を 46 で分類して個数を数える。余り 3 重ループで和が 0 の組の積を加える。
- **047 Monochromatic Diagonal** — 色を mod 3 に符号化して対角線条件を文字列照合へ変形。各色パターンについて Z-algorithm/KMP で一致長を集計する。
- **048 I will not drop out** — 各問題を「部分点 `B`」「満点への追加 `A-B`」の 2 つの 1 分価値に分け、上位 K 個を取る。
- **049 Flip Digits 2** — 区間 `[L,R]` を頂点 `L-1,R` を結ぶ辺とみなす。コスト順 Kruskal で 0..N を連結する最小全域木。
- **050 Stair Jump** — 最後が 1 段か L 段かで `dp[i]=dp[i-1]+dp[i-L]`（範囲外は 0）。

## 051–060

- **051 Typical Shop** — 半分全列挙。選択数ごとに部分和をソートし、反対側の部分和を二分探索して上限以下の個数を足す。
- **052 Dice Product** — 各サイコロで選ぶ目は独立。各サイコロの目の総和を掛け、mod を取る。
- **053 Discrete Dowsing** — 山型（単峰）列への問い合わせは三分探索。`mid, mid+1` の大小で最大値がある側を半分近くに絞る。
- **054 Takahashi Number** — 論文を頂点に加えた二部グラフを作る。研究者 1 から BFS した距離を 2 で割る。
- **055 Select 5** — 5 重ループでも `N≤100` なら間に合う。途中ごとに mod を取って積のオーバーフローを避ける。
- **056 Lucky Bag** — `dp[i][sum]` を i 日目までの到達可否にし、A/B の遷移元を記録する。終点から復元して文字列を出す。
- **057 Flip Flap** — スイッチ操作を GF(2) の連立一次方程式にする。掃き出し法で階数を求め、解数は `2^(変数数-rank)`。
- **058 Original Calculator** — `f(x)=(x+digit_sum(x)) mod 100000` の関数グラフ。初訪問時刻で前周期・周期を検出し、K を飛ばす。
- **059 Many Graph Queries** — 到達可能性問い合わせを 64 件程度の塊に分ける。始点集合を bitset として DAG 上を伝播させ、各塊をまとめて処理する。
- **060 Chimera** — 各位置を頂点とする最長増加部分列を左・右から計算。`LIS_left[i]+LIS_right[i]-1` の最大。

## 061–070

- **061 Deck** — 両端追加・k 番目参照は deque（または前後配列）で管理する。
- **062 Paint All** — 「必要な色がすべて既知なら塗れる」を逆向きに処理。使われる側から隣接を減らし、条件を満たした頂点を queue に入れる。
- **063 Monochromatic Subgrid** — 行集合を全探索。全選択行で同じ値の列だけ数え、`選択行数 × 列数` の最大を取る。
- **064 Uplift** — 隣接差分 `D[i]=A[i+1]-A[i]` の絶対値和を持つ。区間加算で変わるのは左右境界の高々 2 箇所。
- **065 RGB Balls 2** — 条件違反となる色数の組を包除原理で除く。組合せ `C(R,r)C(G,g)C(B,b)` を、一変数を走査＋累積和で高速集計する。
- **066 Various Arrays** — 期待値の線形性で順序対ごとに分ける。区間一様乱数 `Xi,Xj` について `P(Xi>Xj)` を端点から O(1) で計算する。
- **067 Base 8 to 9** — 文字列を 8 進数として整数化→9 進表記へ変換→`8` を `5` に置換、を K 回繰り返す。先頭 0 に注意。
- **068 Paired Information** — 辺の「和」制約は符号を交互に変えた potential として保持できる。重み付き Union-Find で連結判定と交代和を答える。
- **069 Colorful Blocks 2** — 隣接色が異なる列：先頭 K、2 個目 K−1、以降 K−2。小さい N/K の例外を分けて累乗を mod で計算する。
- **070 Plant Planning** — Manhattan 距離和は x 座標・y 座標で独立。最小値はそれぞれの中央値で達成される。

## 071–080

- **071 Fuzzy Priority** — トポロジカル順序を DFS で列挙。入次数 0 の未使用頂点を次候補にし、K 個出たら打ち切る。
- **072 Loop Railway Plan** — 各空きマスを始点に単純路 DFS。始点へ戻る長さ 4 以上の閉路の最大を探す。
- **073 We Need Both a and b** — 根付き木 DP。部分木を切り分けたとき、根を含む連結成分が a のみ／b のみ／両方、の 3 状態を畳み込む。
- **074 ABC String 2** — 文字 A/B/C を 0/1/2 とみなすと、操作回数は下位桁からの繰り上がりで決まる。各文字の寄与 `value×2^位置` を合計する。
- **075 Magic For Balls** — 素因数の個数（重複込み）を `m` とする。1 回で高々 2 倍にしか増やせないので、答えは最小の `t` with `2^t≥m`。
- **076 Cake Cut** — 全体和が 10 の倍数でなければ不可。正数列を 2 倍して尺取り法で和 `total/10` の連続区間を探す。
- **077 Planes on a 2D Plane** — 時刻 T 後に到達できる向きごとに二部グラフを張り、最大二部マッチング（最大流）。対応から各飛行機の向きを復元する。
- **078 Easy Graph Problem** — 各頂点について、自分より番号が小さい隣接頂点の数だけ数え、ちょうど 1 の頂点を数える。
- **079 Two by Two** — 左上から順に 2×2 操作量を強制する。最後の行・列まで処理後に一致するか確認し、操作量絶対値和を出す。
- **080 Let's Share Bit** — 包除原理。選んだ条件の OR を `S` とすると、S の 1 ビットをすべて含む数の個数は `2^(D-popcount(S))`。

## 081–090

- **081 Friendly Group** — 座標値が小さい 2 次元点。高さの幅 K を固定して掃き、体重方向の幅 K の矩形内個数を 2D 累積和（または頻度表）で最大化する。
- **082 Counting Numbers** — 同じ桁数の範囲ごとに分割し、等差数列の和 `Σx` を mod で足す。`/2` は mod 逆元で処理する。
- **083 Colorful Graph** — 次数が大きい頂点だけを heavy にする。heavy の更新時刻・色を遅延保持し、各頂点の質問時に自分と heavy 隣接点の最新更新を見る。
- **084 There are two types of characters** — 全部分文字列数から、同じ文字だけの連続ブロック内部分文字列数を引く。
- **085 Multiplication 085** — `a≤b≤c, abc=K` を満たす約数組を列挙。a, b を小さい順に動かし、残りが割り切れるか確認する。
- **086 Snuke's Favorite Arrays** — ビットごとに独立。各ビットについて N 個の 0/1 割当を全探索し、OR 制約を満たす個数を掛け合わせる。
- **087 Chokudai's Demand** — 未定辺を X にした最短路の「距離 ≤ P の組数」は X について単調非増加。Floyd-Warshall + 二分探索で `f(X)=K` の区間長を求める。
- **088 Similar but Different Ways** — 禁止ペアを避ける部分集合 DP を、同一和ごとに保持する。異なる 2 通りを見つけたら復元し、共通カードは両者に含める。
- **089 Partitions and Inversions** — 尺取り＋Fenwick Tree で各右端に対する「転倒数 ≤ K」の最左端を求める。`dp[r]` は許される切れ目の dp 累積和。
- **090 Tenkei90's Last Problem** — 区間最小値の条件を「値ごとの許容される連続長」に読み替える。K 以下の状態 DP から線形漸化式を作り、巨大 N は多項式／行列の高速べき乗で飛ばす。

## 使い方

1. まず上の 1 行だけを見て方針を再現する。
2. 再現できなければ、対応する `.py` と公式解説を読む。
3. 解き直し後に、このメモへ「自分が詰まった条件・実装上の罠」を追記する。
